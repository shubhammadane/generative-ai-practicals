# Generative AI Practicals - BT23F05F019

This folder contains my implementations for Experiments 1 to 4 from the Generative AI laboratory README.

## Practicals

1. **Generative AI vs Discriminative Models**: compares a discriminative digit classifier with a generative autoencoder using a local handwritten-digits dataset.
2. **Probabilistic Modeling and Synthetic Data**: fits a Gaussian distribution and generates reproducible synthetic samples.
3. **Transformer-Based Language Models and Text Generation**: demonstrates tokenization, embeddings, self-attention, and local next-token generation without a model download.
4. **Prompt Engineering and RAG**: builds a TF-IDF retrieval pipeline and creates a context-grounded prompt that instructs the assistant not to invent unsupported facts.

## Execution

Open each `.ipynb` file in Jupyter or VS Code and run the code cell. The notebooks use a fixed random seed where randomness is involved. Required packages are `numpy`, `matplotlib`, `scipy`, and `scikit-learn`.

The notebooks are intentionally lightweight and do not require a GPU, API key, or interactive input. Practical 3 and Practical 4 use local demonstrations so they can execute reliably offline.
